🟢
Avantage du Grove Base Shield

Le Grove Base Shield élimine tout câblage fil-à-fil pour le LCD (port I2C) et le FSR (port A0). Les connecteurs standardisés 4 broches (VCC · GND · SIG · NC) réduisent les erreurs de câblage et accélèrent le montage.

ℹ️
LCD Grove — branchement direct, zéro câblage

Le LCD 16×2 I²C Grove se branche directement sur l'un des deux ports I2C du Grove Base Shield via son câble 4 fils natif. Aucun câblage supplémentaire n'est nécessaire. C'est le principal avantage du shield pour ce composant.

05 Schéma de câblage complet — Avec Grove Shield

Le FSR 402 est intégré dans un pont diviseur de tension :

V_OUT = ( R_M × V+ ) / ( R_M + R_FSR )

La résistance R_M = 10 kΩ n'est pas intégrée au Grove Shield — elle doit être câblée en externe entre la broche SIG et GND du câble Grove, directement sur le fil ou sur une mini breadboard.

🟢
Ce que le Grove Shield simplifie

Le LCD I²C se branche en plug-and-play sur le port I2C. Plus aucun fil individuel SDA/SCL à gérer. Le port A0 fournit directement VCC, GND et SIG pour le pont diviseur.

⚠️
Ce que le Grove Shield ne fait pas

La résistance de mesure R_M = 10 kΩ doit toujours être câblée manuellement entre SIG (A0) et GND. Elle n'est pas intégrée au shield ni au FSR 402.

🔧
Solution pratique pour la résistance 10 kΩ

Couper un câble Grove femelle côté FSR, puis souder la résistance de 10 kΩ directement entre le fil SIG (blanc/jaune) et le fil GND (noir). Protéger avec de la gaine thermorétractable. Le FSR 402 se connecte ensuite entre VCC (rouge) et SIG (blanc/jaune).

📌
Fixation du FSR 402 sur le mors

Coller le FSR 402 sur l'un des deux mors de la pince avec un point de colle. Centrer la zone active (Ø 14,68 mm). La fermeture étant symétrique, le choix du mors n'a pas d'incidence sur la mesure.

06 Code Arduino — Version FSR 402 + Grove Shield
sketch_fsr402_grove.ino Arduino C++ 
// ═══════════════════════════════════════════════════════════════
// Bras Robot DOBOT — Mesure de force de préhension
// Capteur  : FSR® 402 (Interlink Electronics)
// Shield   : Grove Base Shield 103030000
//   FSR402 + R_M (10kΩ) → Port analogique A0 du Grove Shield
//   LCD rgb_lcd          → Port I2C du Grove Shield (plug-and-play)
// ═══════════════════════════════════════════════════════════════

#include <Wire.h>       // Communication I²C (LCD via Grove I2C)
#include "rgb_lcd.h"    // Bibliothèque LCD Grove

rgb_lcd lcd;

// ── Constantes ──────────────────────────────────────────────────
// FSR 402 branché sur le port A0 du Grove Base Shield
// Pont diviseur : 5V → FSR402 → nœud SIG(A0) → 10kΩ → GND
const int   sensorPin = A0;       // Port A0 Grove Shield → broche A0 Arduino
const float VCC       = 5.0;      // Tension alimentation Grove Shield (V)
const float RM        = 10000.0; // Résistance de mesure externe (10 kΩ)
const int   colorR    = 0;
const int   colorG    = 0;
const int   colorB    = 0;

// ── Variables ────────────────────────────────────────────────────
int   rawValue = 0;    // Valeur brute ADC 10 bits (0–1023)
float vOut     = 0.0; // Tension au nœud SIG du Grove A0 (V)
float rFSR     = 0.0; // Résistance du FSR 402 calculée (Ω)
float force    = 0.0; // Force de préhension estimée (N)

// ── Setup ────────────────────────────────────────────────────────
void setup() {
  Serial.begin(9600);
  // LCD connecté sur le port I2C du Grove Shield
  // Wire.begin() appelé automatiquement par rgb_lcd
  lcd.begin(16, 2);
  lcd.setRGB(colorR, colorG, colorB);
  lcd.print("Force (N) :");
  delay(1000);
}

// ── Loop ─────────────────────────────────────────────────────────
void loop() {

  // 1. Lecture brute ADC — port A0 Grove Shield
  rawValue = analogRead(sensorPin);

  // 2. Conversion ADC → tension V_OUT au nœud SIG
  vOut = rawValue * (VCC / 1023.0);

  // 3. Calcul résistance FSR 402 via pont diviseur inversé
  //    V_OUT = RM*VCC/(RM+R_FSR) → R_FSR = RM*(VCC/V_OUT - 1)
  if (vOut > 0.01) {   // Évite division par zéro (FSR non actionné)
    rFSR = RM * ((VCC / vOut) - 1.0);

    // 4. Conversion R_FSR → Force (N)
    //    Loi empirique basée sur courbe datasheet FSR 402
    //    F(N) ≈ 1 / (R_FSR × 4e-5)  ← à affiner par calibration
    force = 1.0 / (rFSR * 4e-5);

    // 5. Limitation à la plage utile du FSR 402 (0,2 N – 20 N)
    force = constrain(force, 0.0, 20.0);
  } else {
    force = 0.0;  // Pince ouverte — aucune force
  }

  // 6. Affichage LCD (port I2C Grove Shield)
  lcd.setCursor(0, 1);
  lcd.print("                "); // Efface la ligne 2
  lcd.setCursor(0, 1);
  lcd.print(force, 2);
  lcd.print(" N    ");

  // 7. Débogage port série (aide à la calibration)
  Serial.print("ADC=");    Serial.print(rawValue);
  Serial.print(" | Vout="); Serial.print(vOut, 3);  Serial.print(" V");
  Serial.print(" | Rfsr="); Serial.print(rFSR, 0);  Serial.print(" Ohm");
  Serial.print(" | F=");    Serial.print(force, 2); Serial.println(" N");

  delay(200);
}

08 Protocole de calibration
📌
Pourquoi calibrer ?

La constante 4e-5 est une valeur de départ issue de la courbe typique de la datasheet FSR 402. Elle doit être ajustée pour chaque montage (géométrie des mors, surface de contact, colle, câble Grove).

1

Préparer une masse étalon

Utiliser une masse connue : 100 g (= 0,981 N) ou 500 g (= 4,905 N). Ces valeurs servent de référence de calibration.

2

Placer la masse entre les mors

Fermer la pince DOBOT sur la masse étalon afin de comprimer le FSR 402 de façon stable. Vérifier que la zone active du capteur est bien en contact.

3

Relever R_FSR via le moniteur série

Ouvrir le moniteur série à 9600 bauds. Lire la valeur Rfsr=XXXX Ohm affichée. Noter cette résistance R_mesurée.

4

Calculer la nouvelle constante

Appliquer : k = 1.0 / (R_mesurée × F_réelle) où F_réelle est la force connue en Newton. Remplacer 4e-5 par la valeur calculée dans le code.

5

Vérifier avec plusieurs masses

Répéter avec 2 à 3 masses différentes (ex. 100 g, 300 g, 500 g) pour valider la linéarité et affiner si nécessaire.

09 Points de vigilance
⚠️
Résistance R_M obligatoire

Le Grove Base Shield n'intègre pas la résistance de mesure 10 kΩ. Elle doit être ajoutée manuellement entre SIG et GND du câble Grove. Sans elle, la mesure est impossible.

⚠️
Hystérésis du capteur

Le FSR 402 présente une hystérésis d'environ +10 % entre montée et descente en force. Les mesures peuvent légèrement différer selon le sens d'application.

✅
LCD — aucun conflit I²C

Le port I2C du Grove Shield est dédié. Le LCD rgb_lcd utilise l'adresse I²C 0x62 par défaut. Aucun conflit avec d'autres périphériques si le port reste exclusif au LCD.

✅
Robustesse mécanique FSR 402

Testé à 10 millions d'actuations à 1 kg / 4 Hz. Parfaitement adapté à un usage pédagogique intensif sans dégradation prématurée.
