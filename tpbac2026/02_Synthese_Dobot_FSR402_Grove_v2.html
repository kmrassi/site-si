05Schéma de câblage complet — Avec Grove Shield

Le FSR 402 est intégré dans un pont diviseur de tension :

V_OUT = ( R_M × V+ ) / ( R_M + R_FSR )

La résistance R_M = 10 kΩ n'est pas intégrée au Grove Shield — elle doit être câblée en externe entre SIG et GND du câble Grove.

┌──────────────────────────────────────────────────────────┐ │ GROVE BASE SHIELD (sur Arduino UNO) │ │ Port A0 Port I2C (LCD) │ │ [VCC|GND|SIG|NC] [VCC|GND|SDA|SCL] │ └────┬────┬────┬─────────────────────────────────────────-─┘ │ │ │ │ │ └──── A0 Arduino ← point de mesure V_OUT │ │ │ │ │ [ 10 kΩ R_M ] ← externe, soudée sur câble Grove │ │ │ │ └──────────────────┘ │ GND commun │ └──── 5V ──── [ FSR 402 ] ← collé sur le mors │ SIG (A0) ── [ 10 kΩ ] ── GND ─────────────────── LCD I²C ─────────────────────────────── Port I2C Grove ──── câble Grove 4 fils ──── LCD rgb_lcd Grove VCC · GND · SDA · SCL ← plug-and-play, aucun câblage manuel
🔧
Solution pratique — intégrer R_M sur le câble Grove

Couper un câble Grove femelle côté FSR. Souder la résistance 10 kΩ entre le fil SIG (blanc) et le fil GND (noir). Connecter ensuite le FSR 402 entre VCC (rouge) et SIG (blanc). Protéger avec de la gaine thermorétractable.

06Code Arduino — Mesure en temps réel
sketch_fsr402_grove.ino Programme de mesure — à téléverser après étalonnage 
// ═══════════════════════════════════════════════════════════════
// Bras Robot DOBOT — Mesure de force de préhension
// Capteur  : FSR® 402   |   Shield : Grove Base Shield 103030000
// FSR402 + R_M (10kΩ)  → Port analogique A0 du Grove Shield
// LCD rgb_lcd            → Port I2C du Grove Shield (plug-and-play)
// ⚠ Mettre à jour K_CALIB après avoir lancé le programme d'étalonnage
// ═══════════════════════════════════════════════════════════════

#include <Wire.h>
#include "rgb_lcd.h"

rgb_lcd lcd;

// ── Constantes ──────────────────────────────────────────────────
const int   sensorPin = A0;
const float VCC       = 5.0;
const float RM        = 10000.0; // Résistance de mesure externe (10 kΩ)

// ⚙ Constante de calibration — mettre à jour après étalonnage
// Valeur par défaut basée sur courbe datasheet FSR 402
const float K_CALIB  = 4e-5;   // ← remplacer par valeur calculée

const int   colorR = 0, colorG = 0, colorB = 0;

// ── Variables ────────────────────────────────────────────────────
int   rawValue = 0;
float vOut     = 0.0;
float rFSR     = 0.0;
float force    = 0.0;

void setup() {
  Serial.begin(9600);
  lcd.begin(16, 2);
  lcd.setRGB(colorR, colorG, colorB);
  lcd.print("Force (N) :");
  delay(1000);
}

void loop() {
  rawValue = analogRead(sensorPin);
  vOut     = rawValue * (VCC / 1023.0);

  if (vOut > 0.01) {
    rFSR  = RM * ((VCC / vOut) - 1.0);
    force = constrain(1.0 / (rFSR * K_CALIB), 0.0, 20.0);
  } else {
    force = 0.0;
  }

  lcd.setCursor(0, 1);
  lcd.print("                ");
  lcd.setCursor(0, 1);
  lcd.print(force, 2); lcd.print(" N");

  Serial.print("ADC=");   Serial.print(rawValue);
  Serial.print(" Vout="); Serial.print(vOut, 3);
  Serial.print(" Rfsr="); Serial.print(rFSR, 0);
  Serial.print(" F=");    Serial.print(force, 2);
  Serial.println(" N");
  delay(200);
}
07Étalonnage pratique — Principe et protocole
⚖️
Pourquoi étalonner ?

Le FSR 402 mesure une résistance, pas directement une force. La constante K_CALIB fait le lien entre les deux. La valeur par défaut 4e-5 est issue de la courbe typique de la datasheet. Chaque montage (géométrie des mors, colle, surface de contact) modifie légèrement cette valeur — l'étalonnage permet de la corriger précisément.

— Masse étalon : comment choisir ?

Une masse étalon est un objet dont on connaît le poids exact. Posée ou serrée sur le capteur, elle exerce une force connue F = m × g (avec g = 9,81 m/s²), ce qui permet de calculer K_CALIB.

⚠️
Ne jamais appuyer avec le doigt

La pression d'un doigt est trop variable et non reproductible. Utiliser exclusivement des masses scolaires en laiton certifiées (celles du laboratoire de physique-chimie) pour garantir une calibration fiable.

— Deux approches d'application de la masse

Option A — Sur le mors

Masse serrée par la pince

Placer un objet de masse connue entre les deux mors, puis commander le DOBOT pour fermer la pince jusqu'à maintenir l'objet. La force exercée sur le FSR correspond approximativement au poids de l'objet.

⚠ La pince serre — elle n'appuie pas verticalement. C'est un étalonnage relatif lié au montage réel.

Option B — Appui direct (plus rigoureux)

Masse posée à plat sur le capteur

Retirer temporairement le FSR du mors. Le poser à plat sur une surface plane et rigide. Déposer directement la masse étalon de 100 g dessus. La force est purement verticale et bien définie.

✓ Plus rigoureux. Recommandé pour une première calibration précise avant de recoller le capteur.

— Calcul de la constante K_CALIB

Le programme d'étalonnage (section 08) affiche directement la valeur R_FSR dans le moniteur série. Il suffit alors d'appliquer la formule suivante :

Formule de calcul de la constante d'étalonnage :

K_CALIB = 1.0 / ( R_FSR_mesuré × F_réelle )

Où R_FSR_mesuré est lu dans le moniteur série (en Ω) et F_réelle est la force connue de la masse étalon en Newton.

Exemple numérique — masse de 100 g (F = 0,981 N) Moniteur série affiche → Rfsr = 25487 Ohm K_CALIB = 1.0 / (25487 × 0.981) K_CALIB = 1.0 / 25003 K_CALIB ≈ 4.00e-5 → remplacer dans le code de mesure
Exemple numérique — masse de 200 g (F = 1,962 N) Moniteur série affiche → Rfsr = 11200 Ohm K_CALIB = 1.0 / (11200 × 1.962) K_CALIB = 1.0 / 21974 K_CALIB ≈ 4.55e-5 → remplacer dans le code de mesure
💡
Conseil — Moyenne sur plusieurs masses

Pour plus de précision, réaliser l'étalonnage avec 3 masses différentes (100 g, 200 g, 500 g), calculer K_CALIB pour chacune, puis utiliser la moyenne des trois valeurs. Cela compense les légères non-linéarités du FSR 402.

08Programme d'étalonnage Arduino — Test sur moniteur série
🔬
Mode d'emploi du programme d'étalonnage

Ce programme est distinct du programme de mesure. Il est conçu pour être utilisé une seule fois (ou à chaque remplacement du capteur) pour déterminer la valeur de K_CALIB. Il affiche toutes les grandeurs intermédiaires dans le moniteur série et guide l'utilisateur étape par étape.

etalonnage_fsr402.ino Programme d'étalonnage — moniteur série à 9600 bauds 
// ═══════════════════════════════════════════════════════════════
// PROGRAMME D'ÉTALONNAGE — FSR® 402 + Grove Base Shield
// ───────────────────────────────────────────────────────────────
// MODE D'EMPLOI :
//   1. Téléverser ce programme sur l'Arduino
//   2. Ouvrir le moniteur série (9600 bauds)
//   3. Suivre les instructions affichées
//   4. Poser la masse étalon sur le capteur quand demandé
//   5. Noter la valeur K_CALIB affichée
//   6. Reporter K_CALIB dans le programme de mesure principal
// ═══════════════════════════════════════════════════════════════

#include <Wire.h>
#include "rgb_lcd.h"

// ── Configuration ───────────────────────────────────────────────
const int   SENSOR_PIN   = A0;
const float VCC          = 5.0;
const float RM           = 10000.0;    // Résistance de mesure (10 kΩ)
const int   NB_MASSES    = 3;          // Nombre de masses étalons utilisées
const int   NB_MESURES   = 20;         // Mesures moyennées par étalon
const int   DELAI_MS     = 100;        // Délai entre deux mesures (ms)
const int   ATTENTE_SEC  = 5;          // Temps de stabilisation (secondes)

// ── Masses étalons (en grammes) — modifier selon disponibilités
float masses_g[NB_MASSES] = {100.0, 200.0, 500.0}; // grammes

// ── Variables globales ──────────────────────────────────────────
float k_valeurs[NB_MASSES]; // Valeurs K calculées pour chaque masse
float r_valeurs[NB_MASSES]; // Résistances mesurées pour chaque masse
rgb_lcd lcd;

// ── Fonctions utilitaires ───────────────────────────────────────

// Lit N fois le capteur et retourne la moyenne
float lire_adc_moyenne(int n) {
  long somme = 0;
  for (int i = 0; i < n; i++) {
    somme += analogRead(SENSOR_PIN);
    delay(DELAI_MS);
  }
  return (float)somme / n;
}

// Convertit ADC moyen → résistance FSR (Ω)
float adc_vers_rfsr(float adc_moy) {
  float vout = adc_moy * (VCC / 1023.0);
  if (vout < 0.01) return -1; // Capteur non actionné
  return RM * ((VCC / vout) - 1.0);
}

// Affiche une ligne de séparation dans le moniteur série
void separateur() {
  Serial.println("──────────────────────────────────────────");
}

// Affiche une LED clignotante sur LCD pendant l'attente
void attendre_stabilisation() {
  for (int s = ATTENTE_SEC; s > 0; s--) {
    Serial.print("  Stabilisation : "); Serial.print(s); Serial.println("s...");
    lcd.setCursor(0, 1); lcd.print("Attente : "); lcd.print(s); lcd.print("s  ");
    delay(1000);
  }
}

// ── Setup ────────────────────────────────────────────────────────
void setup() {
  Serial.begin(9600);
  lcd.begin(16, 2);
  lcd.setRGB(0, 0, 0);

  delay(500);
  separateur();
  Serial.println("   ÉTALONNAGE FSR 402 — Bras Robot DOBOT");
  Serial.println("   Grove Base Shield 103030000 — Port A0");
  separateur();
  Serial.println();
  Serial.println("CONFIGURATION :");
  Serial.print  ("  Resistance de mesure R_M = "); Serial.print(RM, 0); Serial.println(" Ohm");
  Serial.print  ("  Alimentation VCC         = "); Serial.print(VCC); Serial.println(" V");
  Serial.print  ("  Mesures par etalon       = "); Serial.println(NB_MESURES);
  Serial.print  ("  Masses utilisees (g)     = ");
  for (int i = 0; i < NB_MASSES; i++) {
    Serial.print(masses_g[i], 0);
    if (i < NB_MASSES - 1) Serial.print(", ");
  }
  Serial.println();
  separateur();

  // Vérification capteur au repos
  Serial.println();
  Serial.println("ETAPE 0 — Vérification capteur au repos");
  Serial.println("  Ne pas appuyer sur le capteur...");
  delay(2000);

  float adc_repos = lire_adc_moyenne(5);
  float v_repos   = adc_repos * (VCC / 1023.0);

  Serial.print("  ADC repos = "); Serial.print(adc_repos, 1);
  Serial.print(" | Vout = "); Serial.print(v_repos, 3); Serial.println(" V");

  if (v_repos < 0.05) {
    Serial.println("  [OK] Capteur au repos : resistance > 10 MOhm");
  } else {
    Serial.println("  [!] Attention : tension repos elevee — verifier cablage");
  }

  // Boucle sur chaque masse étalon
  for (int i = 0; i < NB_MASSES; i++) {
    separateur();
    float masse_kg = masses_g[i] / 1000.0;
    float force_n  = masse_kg * 9.81;

    Serial.println();
    Serial.print("ETAPE "); Serial.print(i + 1);
    Serial.print(" — Masse : "); Serial.print(masses_g[i], 0);
    Serial.print(" g  |  Force : "); Serial.print(force_n, 3); Serial.println(" N");
    Serial.println("  >>> Poser la masse sur le capteur maintenant");
    lcd.clear();
    lcd.print("Poser "); lcd.print(masses_g[i], 0); lcd.print("g");

    attendre_stabilisation();

    // Acquisition moyennée
    Serial.print("  Acquisition de "); Serial.print(NB_MESURES); Serial.println(" mesures...");
    lcd.setCursor(0, 1); lcd.print("Mesure en cours ");

    float adc_moy = lire_adc_moyenne(NB_MESURES);
    float vout    = adc_moy * (VCC / 1023.0);
    float rfsr    = adc_vers_rfsr(adc_moy);
    float k       = (rfsr > 0) ? (1.0 / (rfsr * force_n)) : 0;

    r_valeurs[i] = rfsr;
    k_valeurs[i] = k;

    // Affichage résultats
    Serial.println("  ┌─ RÉSULTATS ──────────────────────────┐");
    Serial.print  ("  │ ADC moyen  = "); Serial.print(adc_moy, 1); Serial.println("
  │ Vout       = "); Serial.print(vout, 4); Serial.println(" V");
    Serial.print  ("  │ R_FSR      = "); Serial.print(rfsr, 0); Serial.println(" Ohm");
    Serial.print  ("  │ Force ref  = "); Serial.print(force_n, 3); Serial.println(" N");
    Serial.print  ("  │ K_CALIB    = "); Serial.print(k, 6); Serial.println("  ←");
    Serial.println("  └──────────────────────────────────────┘");

    lcd.clear(); lcd.print("K="); lcd.print(k, 5);
    lcd.setCursor(0,1); lcd.print("R="); lcd.print(rfsr, 0); lcd.print(" Ohm  ");

    Serial.println("  >>> Retirer la masse du capteur");
    delay(3000);
  }

  // Synthèse finale
  separateur();
  Serial.println();
  Serial.println("SYNTHÈSE DES RÉSULTATS D'ÉTALONNAGE");
  Serial.println();
  Serial.println("  Masse(g) | R_FSR(Ohm) | F(N)  | K_CALIB");
  Serial.println("  ─────────|────────────|───────|─────────────");

  float k_somme = 0;
  for (int i = 0; i < NB_MASSES; i++) {
    float f = (masses_g[i] / 1000.0) * 9.81;
    Serial.print("  "); Serial.print(masses_g[i], 0);
    Serial.print("g    | "); Serial.print(r_valeurs[i], 0);
    Serial.print("  | "); Serial.print(f, 3);
    Serial.print(" | "); Serial.println(k_valeurs[i], 6);
    k_somme += k_valeurs[i];
  }

  float k_moyenne = k_somme / NB_MASSES;

  Serial.println();
  separateur();
  Serial.println("  ★ CONSTANTE À REPORTER DANS LE CODE ★");
  Serial.println();
  Serial.print("  const float K_CALIB = ");
  Serial.print(k_moyenne, 6);
  Serial.println(";");
  separateur();
  Serial.println("  Étalonnage terminé. Reporter K_CALIB");
  Serial.println("  dans sketch_fsr402_grove.ino et");
  Serial.println("  téléverser le programme de mesure.");
  separateur();

  lcd.clear(); lcd.print("K_MOY="); lcd.print(k_moyenne, 5);
  lcd.setCursor(0,1); lcd.print("Etalonn. OK !");
}

// Loop vide — étalonnage effectué une seule fois dans setup()
void loop() {}

10Points de vigilance
⚠️
Résistance R_M obligatoire

Le Grove Base Shield n'intègre pas la résistance 10 kΩ. Elle doit être ajoutée manuellement entre SIG et GND du câble Grove. Sans elle, la mesure est impossible.

⚠️
Ordre des programmes

Toujours lancer le programme d'étalonnage en premier, noter K_CALIB, puis le reporter dans le code de mesure avant de le téléverser.

✅
LCD — aucun conflit I²C

Le LCD rgb_lcd utilise l'adresse I²C 0x62. Aucun conflit si le port I2C reste exclusif au LCD sur le Grove Shield.

✅
Robustesse FSR 402

Testé à 10 millions d'actuations à 1 kg / 4 Hz. Adapté à un usage pédagogique intensif sans dégradation prématurée.
