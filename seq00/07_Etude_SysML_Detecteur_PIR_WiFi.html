Lecture du diagramme
  • Acteur humain (Utilisateur) à gauche : il configure le détecteur, reçoit les notifications et remplace la pile.

Lecture du diagramme

Le losange plein indique une relation de composition : le « Détecteur PIR WiFi » est constitué de 7 blocs. Le Module PIR assure la détection, le Capteur de Luminosité ajuste la sensibilité selon l'éclairage ambiant, et le Module WiFi relie l'Unité de Contrôle au smartphone et aux assistants vocaux.

Lecture du diagramme
  • Les petits carrés représentent les ports par lesquels les blocs échangent des flux (item flows).
  • Les flèches pleines bleues = flux d'information (signal de détection, niveau de luminosité, alerte/commande domotique).
  • Les flèches orange en pointillés = flux d'énergie : le module d'alimentation (pile CR123 3V) distribue l'énergie vers l'ensemble des modules.
  • L'Unité de Contrôle reçoit le signal du module PIR et le niveau de luminosité, puis pilote le module WiFi pour émettre l'alerte.

  • Flèches pleines = appels synchrones ; flèches pointillées = messages de retour.
