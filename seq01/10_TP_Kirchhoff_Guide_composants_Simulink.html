SEQ 1 — TP Matlab · Lois de Kirchhoff

Trouver les composants Simulink en MATLAB R2025b

Les captures d'écran du support de TP viennent de MATLAB R2016a. L'interface a changé depuis, mais deux méthodes fonctionnent quelle que soit la version — voici comment retrouver chaque composant sans se perdre dans les bibliothèques.
La méthode la plus rapide et la plus fiable Plutôt que de fouiller dans l'arborescence des bibliothèques (qui change d'une version à l'autre), utilisez le Quick Insert : double-cliquez sur une zone vide de votre schéma Simulink, tapez le nom du composant, puis validez avec Entrée. Cette méthode fonctionne à l'identique dans toutes les versions récentes de MATLAB, y compris R2025b.

1Méthode 1 — Quick Insert (recommandée)

Double-cliquez sur une zone vide de la fenêtre Simulink (pas sur un composant déjà présent).
Tapez le nom du composant recherché (voir le tableau ci-dessous pour le nom exact à utiliser pour chaque élément du TP).
Vérifiez la bibliothèque affichée sous le nom du bloc dans la liste de résultats : plusieurs blocs peuvent porter un nom proche mais appartenir à des bibliothèques différentes (l'ancienne « Specialized Power Systems » et la nouvelle « Simscape / Foundation Library », par exemple). Utilisez les flèches du clavier pour naviguer et le panneau de droite pour lire la description avant de valider.
Validez avec Entrée : le composant est placé directement à l'endroit où vous avez double-cliqué.

2Méthode 2 — Barre de recherche du Library Browser

C'est la méthode montrée dans le support de TP d'origine : elle existe toujours en R2025b. Cliquez sur l'icône Simulink Library Browser (le petit logo dans le ruban, section Simulink) ou utilisez le raccourci Ctrl+Shift+L, puis tapez le nom du composant dans le champ de recherche en haut de la fenêtre.

À savoir : depuis quelques versions, MathWorks a regroupé une grande partie des anciens blocs électriques (SimPowerSystems / SimElectronics) dans une bibliothèque unifiée Simscape Electrical, elle-même construite sur la Simscape Foundation Library. Les chemins ont donc changé par rapport aux captures R2016a, mais les noms des composants sont restés identiques — c'est pourquoi chercher par nom (méthode 1 ou 2) reste plus sûr que de suivre un chemin de menus mémorisé.

4En cas de doute sur un bloc trouvé

Comparez les ports : ouvrez le bloc trouvé et vérifiez qu'il possède les mêmes bornes (+ / − ou électriques) que celui du schéma fourni dans le TP.
Lisez la description dans le panneau de droite du Quick Insert ou du Library Browser : elle indique le rôle exact du bloc et la bibliothèque à laquelle il appartient.
En dernier recours, demandez à votre professeur de confirmer le bloc à utiliser — certains TP anciens référencent des blocs de bibliothèques aujourd'hui remplacées.
